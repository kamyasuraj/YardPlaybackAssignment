Page contract

Every control calls one Unity object by name: YardPlayer, through unityInstance.SendMessage("YardPlayer", method, value). That object carries only these six methods.

ControlCallValueWhat it does
LoadSendMessage("YardPlayer", "Load", script)the whole script as one string (JSON text)Places the opening markers, ready to play. A bad script is rejected (the reason shows in the scene) and the current one stays.
StartSendMessage("YardPlayer", "Play")nonePlays the cues in order from the opening.
PauseSendMessage("YardPlayer", "Pause")noneFreezes motion and the cue clock.
ResumeSendMessage("YardPlayer", "Resume")noneContinues the same cue.
SpeedSendMessage("YardPlayer", "SetSpeed", n)number, 1 or 21× or 2×. No cue is skipped or repeated. Other values are ignored.
SkipSendMessage("YardPlayer", "Skip")noneSnaps to closing at once. A second Skip stays there.

When playback finishes (played through, or by Skip), Unity dispatches a yard:finished event on window. Its event.detail is the finished payload as a JSON string: who is left, with each lane and load. It fires once per loaded script.

window.addEventListener("yard:finished", e => {
  const finished = JSON.parse(e.detail);
  // {"ticket":"shift-04","left":[{"id":"fork-1","lane":"north","load":2},{"id":"fork-2","lane":"south","load":0}]}
});
